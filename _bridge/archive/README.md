# _bridge/archive

チャット側が置く、指示と報告の番号つきの写し（2026-09-27 本人決定）。

## なぜ置くか

`_bridge/to-cc.md`・`to-cc-detail.md`・`from-cc.md`・`from-cc-detail.md` は、毎ターン同じ名前で上書きされる。CC が `_bridge/` をコミットしなかったターンに、チャット側が次の指示で上書きしたため、次の 2 つがどのコミットにも入らなかった。

- turn 81 の指示
- turn 78 の報告

これを防ぐため、次の 2 つを行う。

- チャット側は、毎ターンの指示をここにも `to-cc_tNN.md`・`to-cc-detail_tNN.md` の名前で置く
- CC は、ほかのコミットを止めたターンでも、終わりに `_bridge/` だけはコミットする

| `to-cc_t83.md`・`to-cc-detail_t83.md` から後 | チャット側が毎ターン置く写し（`_bridge/to-cc.md` と同じ中身） |
