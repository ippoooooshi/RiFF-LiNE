## 7. alphaTab 1.8.4 で確かめたこと（型定義と実装）

- `Note.stringTuning` は `staff.capo + 開放弦`、`calculateRealValue` は `fret + stringTuning − transpositionPitch`（`dist/alphaTab.core.mjs`）。A14 は (b) の見込み（実機の音では確かめていない）
- 再生中にパンを変える公開の口は無い（`changeTrackPan|setChannelPan|ChannelPan` で d.ts を grep、ヒット 0 件）。`changeTrackVolume`・`changeTrackSolo`・`changeTrackMute` はある
- `playNote`・`playBeat`・`playOneTimeMidiFile` は鳴っている曲を止める（d.ts の注記）。`loadMidiForScore` も再生を止める
- 同じ `Score` を描き直しても MIDI は作り直さない（`_internalRenderTracks` の `score !== this.score` の分岐）
- alphaTab のメトロノームは打楽器の 33 番を同じ強さで鳴らすだけ（`SynthConstants.MetronomeKey = 33`）
- `PlaybackInformation` の `volume`・`balance` は 0〜16（8 が中央）、MIDI の CC は `_toChannelShort`（値 × 8）。準備ができたときに `playbackInfo.volume / 16` をチャンネルの音量に渡している
- `playbackSpeed` は 0.125〜8.0、`ScrollMode` に `Off`・`OffScreen` がある
