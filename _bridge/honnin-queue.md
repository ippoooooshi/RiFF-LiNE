## 39. 初回起動のオンボーディングで、曲が 0 件のときに「曲を開く操作」をどう示すか

- **一言で**：初めて起動したときのオンボーディングの 2 つ目のステップは「曲を開く操作」を矢印で示すが、初めて起動したときは曲がまだ 1 つも無いのがふつうで、矢印が指す曲が画面に無い。そのときの見せ方を決める
- **見立て**：案 C

1. **何を決めるか**：オンボーディングの ②「曲を開く操作」で、曲一覧に曲が 0 件のとき、矢印をどこへ向け、何と書くか
2. **なぜ決まっていないか**：
   - 詳細設計（screens-navigation.md 14 節）は、② の矢印を「曲の右クリックの「開く」」に向けると書いている。曲が 0 件のときは右クリックする曲が無く、矢印の行き先が無い
   - 判定役が、上位の「②曲を開く操作」を、ありうる状態（初回起動はふつう 0 件）で満たす形が無いとした（turn 121 の段 ③）。利用者に見える形なので、詳細設計では決めずに積んだ。止めなかったのは、ほかの 4 ステップと表示の条件は書けるため
3. **原文**：
   - 基本設計 03:321「| 提示内容 | ①新規曲作成ボタンの場所、②曲を開く操作、③設定・ゴミ箱の場所、④並べ替え、⑤グリッド／リストの切り替えの5つとし、これ以外は示さない（2026-10-03 本人決定） |」
   - 詳細設計 screens-navigation.md 14 節「矢印が指す先は、① が 6.1 節の「新規作成」ボタン、② が曲の右クリックの「開く」（6.3 節）、…」
4. **選べる案**：

| | 案 A | 案 B | 案 C |
|---|---|---|---|
| 形 | 曲があるときは今の形（一覧の先頭の曲に矢印）。0 件のときだけ、矢印を曲を並べる場所（空の一覧）に向け、「曲ができたら、ここで曲を右クリックして「開く」で開きます」の類の短い文を出す | 0 件のときは ② を飛ばし、4 ステップにする | 曲があってもなくても、矢印はいつも曲を並べる場所に向け、文で右クリックの「開く」を説明する |
| ステップの数 | いつも 5 | 0 件のときは 4（本人が決めた「5 ステップ」と合わない） | いつも 5 |
| 見え方の数 | 2 通り | 2 通り | 1 通り |

5. **見立て**：**案 C**
   - 根拠：初回起動はふつう 0 件なので、ほとんどの人が見る形は案 A と同じ。曲の有無で見え方を変えずに済み、作る形が 1 つで済む。案 B は 2026-10-03 の「5 ステップ」の決定と合わない
   - 反対する理由：曲があるとき（設定の「アプリ情報」から出し直したとき）は、実物の曲を指すほうが分かりやすい。案 C は、曲があっても場所しか指さない
6. **決めた後**：
   - screens-navigation.md 14 節の ② の矢印の先と文を直す
   - 基本設計から詳細設計への 1 件（②曲を開く操作）を判定し直す
   - 取り消すとき：14 節の ② の文を今の形に戻す
